# FOCUSVERSE

> Turn your time into progress.

FOCUSVERSE is a futuristic productivity and study universe.

## Features

- Focus Timer
- Custom Focus Sessions
- XP
- Levels
- Streaks
- Missions
- World Building
- Focus Pet
- Statistics
- Community
- Friends
- Android
- Windows

## Website

The website is deployed using GitHub Pages.

## Releases

Android APK and Windows builds are distributed through GitHub Releases.

## Updating

Create a new GitHub Release with:

- focusverse.apk
- focusverse-windows.zip

The website automatically detects the latest GitHub release.
